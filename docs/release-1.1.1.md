CodexUsageNotch 将 Codex 的剩余额度、重置时间和完整重置次数放进 Windows 桌面客户端标题栏中的小胶囊。

- Pro 保留绿色单环；Plus 使用蓝色周额度外环和绿色 5 小时内环，显示 `5h 99%/本周 80%`。
- 自动适配深色、浅色主题、窗口宽度和系统 DPI；Plus 与 Pro 等高，三段文字保持对齐。
- 左侧额度与右侧完整重置可展开详情；中间重置时间为纯展示，点击无操作。
- 每 10 秒只读刷新，随 Codex 前台窗口显示，右键可刷新或退出。

下载 `CodexUsageNotch.exe` 即可运行，无需另装 .NET。需要本机已安装 Codex 桌面客户端并登录账号。ZIP 便携包附带四张效果图、Pro/Plus 明暗演示入口及使用说明。

已通过 7 项功能自检、明暗主题下三档窗口宽度的布局和交互检查，以及单文件 EXE 启动检查。Pro 已读取真实账号；Plus 使用模拟响应验证，尚未使用真实 Plus 账号测试。
